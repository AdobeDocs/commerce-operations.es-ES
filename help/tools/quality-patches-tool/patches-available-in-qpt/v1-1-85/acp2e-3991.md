# ACP2E-3991: La dirección IP del cliente no está determinada correctamente

El parche ACP2E-3991 corrige el problema en el que la dirección IP del cliente no se determina correctamente y se guarda como `127.0.0.1` en el campo `remote_ip` de la tabla `sales_order`. Esta revisión está disponible cuando está instalado [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.85. El ID del parche es ACP2E-3991. Tenga en cuenta que este problema se corrige en Adobe Commerce 2.4.9.

## Productos y versiones afectados

**El parche se ha creado para la versión de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.7-p6, 2.4.8-p5

**Compatible con versiones de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.7 - 2.4.8-p5

>[!NOTE]
>
>El parche podría ser aplicable a otras versiones con las nuevas versiones de [!DNL Quality Patches Tool]. Para comprobar si el parche es compatible con su versión de Adobe Commerce, actualice el paquete `magento/quality-patches` a la última versión y compruebe la compatibilidad en la página [[!DNL Quality Patches Tool]: buscar parches &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilice el ID de parche como palabra clave de búsqueda para localizar el parche.

## Problema

Problema donde la dirección IP del cliente no se determina correctamente y se guarda como `127.0.0.1` en el campo `remote_ip` de la tabla `sales_order`.

<u>Pasos a seguir</u>:

1. Configuración del servidor de aplicaciones de GraphQL en una instancia de Commerce Cloud.
1. Realice un pedido a través de GraphQL.
1. Compruebe el campo `remote_ip` de la tabla `sales_order` para ver el pedido que ha creado.
1. Compruebe el registro de acceso.

<u>Resultados esperados</u>:

Se registra la dirección IP correcta, incluso cuando la solicitud se enruta a través de GraphQL.

<u>Resultados reales</u>:

El campo `remote_ip` se guarda como `127.0.0.1` en lugar de la dirección IP real del cliente.
