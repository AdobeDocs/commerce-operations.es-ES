# ACP2E-4593: La página de CMS de Restricción de Sitio Web es errónea y se suministra en el sitio web secundario en tiendas de varios sitios web

El parche ACP2E-4593 corrige el problema en el que la página CMS de restricción de sitio web incorrecta se sirve en la tienda del sitio web secundario en configuraciones de varios sitios web porque la clave de caché de la página de aterrizaje no tiene ámbitos por sitio web. Esta revisión está disponible cuando está instalado [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82. El ID del parche es ACP2E-4593. Este problema está programado para solucionarse en Adobe Commerce 2.4.10.

## Productos y versiones afectados

**El parche se ha creado para la versión de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.5-p15

**Compatible con versiones de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.5 - 2.4.9

>[!NOTE]
>
>El parche podría ser aplicable a otras versiones con las nuevas versiones de [!DNL Quality Patches Tool]. Para comprobar si el parche es compatible con su versión de Adobe Commerce, actualice el paquete `magento/quality-patches` a la última versión y compruebe la compatibilidad en la página [[!DNL Quality Patches Tool]: buscar parches &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=es). Utilice el ID de parche como palabra clave de búsqueda para localizar el parche.

## Problema

La página de CMS de restricción de sitio web incorrecta se proporciona en la tienda del sitio web secundario en configuraciones de varios sitios web porque la clave de caché de la página de aterrizaje no tiene ámbitos por sitio web.

<u>Requisitos previos</u>:

El inventario está instalado.

<u>Pasos a seguir</u>:

1. Cree dos sitios web.
1. Cree dos páginas de CMS, agregue texto diferente a cada página en la sección de contenido y asigne cada página a un sitio web diferente.
1. Habilite las restricciones de sitio web y configure una página de aterrizaje para su sitio web correspondiente.
1. Asegúrese de que el almacenamiento en caché esté habilitado.
1. Abra la tienda del primer sitio web y compruebe el contenido de la página de aterrizaje mostrada.
1. Abra la tienda del segundo sitio web y observe que aún muestra el contenido de la página de aterrizaje del primer sitio web.

<u>Resultados esperados</u>:

Cada sitio web muestra su página de CMS correspondiente correctamente en la tienda.

<u>Resultados reales</u>:

Ambos sitios web muestran la misma página de CMS, que es la página a la que se accedió primero.
