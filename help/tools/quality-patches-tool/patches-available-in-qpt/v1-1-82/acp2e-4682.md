# ACP2E-4682: Las páginas de tienda que comprueban la cotización `isActive` crean registros de cotización vacíos

El parche ACP2E-4682 corrige el problema en el que al visitar una página de tienda que comprueba el estado de la cotización `isActive` se crean registros de cotización vacíos cada vez que se carga la página. Esta revisión está disponible cuando está instalado [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82. El ID del parche es ACP2E-4682. Este problema está programado para solucionarse en Adobe Commerce 2.4.10.

## Productos y versiones afectados

**El parche se ha creado para la versión de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.7-p8

**Compatible con versiones de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.5 - 2.4.9

>[!NOTE]
>
>El parche podría ser aplicable a otras versiones con las nuevas versiones de [!DNL Quality Patches Tool]. Para comprobar si el parche es compatible con su versión de Adobe Commerce, actualice el paquete `magento/quality-patches` a la última versión y compruebe la compatibilidad en la página [[!DNL Quality Patches Tool]: buscar parches &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilice el ID de parche como palabra clave de búsqueda para localizar el parche.

## Problema

Al visitar una página de tienda que comprueba el estado de la cotización `isActive`, se crea un registro de cotización vacío cada vez que se carga la página.

<u>Pasos a seguir:</u>

1. Personalice una página de producto de tienda y agregue un bloque que compruebe el estado `isActive` de la oferta.
1. Inicie sesión en una cuenta de cliente.
1. Vuelva a cargar la página del producto en la tienda.
1. Ejecute la siguiente consulta:

   ```
   SELECT COUNT(*) FROM quote;
   ```

1. Observe que el recuento de presupuestos aumenta cada vez que se carga la página del producto.

<u>Resultados esperados:</u>

1. No se crea un registro de comillas vacío cuando se carga la página.

<u>Resultados reales:</u>

1. Se crea un registro de comillas vacío cada vez que se visita una página que contiene la comprobación de comillas `isActive`.
