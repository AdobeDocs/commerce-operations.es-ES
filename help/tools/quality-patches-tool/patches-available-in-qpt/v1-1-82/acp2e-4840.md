# ACP2E-4840: la consulta de productos de GraphQL devuelve una cantidad nula para los productos en stock en existencias de inventario personalizadas

El parche ACP2E-4840 corrige el problema en el que el campo de cantidad de la consulta GraphQL de productos devuelve nulo para los productos que están en stock y disponibles para la venta en stock de inventario personalizado. Esta revisión está disponible cuando está instalado [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82. El ID del parche es ACP2E-4840. Este problema está programado para solucionarse en Adobe Commerce 2.4.10.

## Productos y versiones afectados

**El parche se ha creado para la versión de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.8-p4

**Compatible con versiones de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>El parche podría ser aplicable a otras versiones con las nuevas versiones de [!DNL Quality Patches Tool]. Para comprobar si el parche es compatible con su versión de Adobe Commerce, actualice el paquete `magento/quality-patches` a la última versión y compruebe la compatibilidad en la página [[!DNL Quality Patches Tool]: buscar parches ](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilice el ID de parche como palabra clave de búsqueda para localizar el parche.

## Problema

El campo de cantidad de la consulta GraphQL de productos devuelve nulo para los productos que están en stock y disponibles para la venta en existencias de inventario personalizadas.

<u>Requisitos previos</u>:

MSI está habilitado.

<u>Pasos a seguir</u>:

1. Cree una nueva fuente.
1. En la barra lateral de Administración, vaya a **[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Stock]**.
1. Haga clic en **[!UICONTROL Add New Stock]**.
1. Expanda **[!UICONTROL Sales Channels]** y seleccione **[!UICONTROL Websites]** donde las existencias estén disponibles.
1. Expanda **[!UICONTROL Sources]**, haga clic en **[!UICONTROL Assign Sources]**, seleccione el origen que desee asignar y haga clic en **[!UICONTROL Done]**.
1. En la barra lateral de Administración, vaya a **[!UICONTROL Catalog]** > **[!UICONTROL Products]** y abra un producto existente en modo de edición.
1. En la sección **[!UICONTROL Sources]**, asigne el origen personalizado, establezca **[!UICONTROL Source Item Status]** en **[!UICONTROL In Stock]**, introduzca un valor distinto de cero para **[!UICONTROL Qty]** y guarde el producto.
1. Confirme en **[!UICONTROL Catalog]** > **[!UICONTROL Products]** que el producto muestra un **[!UICONTROL Salable Quantity]** distinto de cero para el sitio web asignado a las existencias personalizadas.
1. Ejecute la siguiente consulta `products` [!DNL GraphQL] para ese SKU con la vista de la tienda asignada al sitio web que usa el archivo de stock personalizado:

   ```
   query {
     products(filter: { sku: { in: ["product_dynamic_1"] } }) {
       items {
         sku
         name
         stock_status
         quantity
         max_sale_qty
       }
     }
   }
   ```

1. Observe la respuesta:

   ```
   {
     "data": {
       "products": {
         "items": [
           {
             "sku": "product_dynamic_1",
             "name": "Simple Product 1",
             "stock_status": "IN_STOCK",
             "quantity": null,
             "max_sale_qty": 10000
           }
         ]
       }
     }
   }
   ```

<u>Resultados esperados</u>:

La respuesta de GraphQL devuelve un valor de cantidad no nulo para los productos que están en stock y que se pueden vender en la tienda o sitio web actual.

<u>Resultados reales</u>:

La respuesta de GraphQL devuelve `quantity = null` mientras que `stock_status` = `IN_STOCK` para productos que están en stock y que se pueden vender en el administrador cuando la tienda usa un stock MSI personalizado.
