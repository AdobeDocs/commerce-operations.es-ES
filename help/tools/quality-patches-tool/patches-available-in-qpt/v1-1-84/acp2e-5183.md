# ACP2E-5183: La implementación de contenido estático falla en PHP 8.5 con `@magento_import`

El parche ACP2E-5183 corrige el problema en el que la implementación de contenido estático falla en PHP 8.5 con el error *El uso de null como desplazamiento de matriz está obsoleto* cuando un archivo de módulo `LESS` utiliza la directiva `@magento_import`. Esta revisión está disponible cuando está instalado [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84. El ID del parche es ACP2E-5183. Este problema está programado para solucionarse en Adobe Commerce 2.4.10.

## Productos y versiones afectados

**El parche se ha creado para la versión de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.9

**Compatible con versiones de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.4 - 2.4.9

>[!NOTE]
>
>El parche podría ser aplicable a otras versiones con las nuevas versiones de [!DNL Quality Patches Tool]. Para comprobar si el parche es compatible con su versión de Adobe Commerce, actualice el paquete `magento/quality-patches` a la última versión y compruebe la compatibilidad en la página [[!DNL Quality Patches Tool]: buscar parches &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilice el ID de parche como palabra clave de búsqueda para localizar el parche.

## Problema

La implementación de contenido estático falla en PHP 8.5 con el error *El uso de null como desplazamiento de matriz está obsoleto* cuando un archivo de módulo `LESS` utiliza la directiva `@magento_import`.

<u>Requisitos previos</u>:

PHP 8.5 está instalado.

<u>Pasos a seguir</u>:

1. Habilite un módulo personalizado que proporcione un archivo `email-inline.less` que contenga un estilo de cuerpo de correo electrónico personalizado y una directiva `@magento_import`.
1. Eliminar contenido estático y archivos generados:

   ```
   rm -rf pub/static/frontend/* var/view_preprocessed/* generated/code/*
   ```

1. Ejecute la implementación de contenido estático mediante la estrategia compacta:

   ```
   bin/magento setup:static-content:deploy --ansi --no-interaction -f -s compact --jobs 4 --no-html-minify
   ```

<u>Resultados esperados</u>:

La implementación de contenido estático se completa correctamente y genera el CSS compilado para el archivo `LESS` proporcionado por el módulo.

<u>Resultados reales</u>:

La implementación de contenido estático se anula al compilar el archivo `email-inline.less` proporcionado por el módulo y los informes:

```
Deprecated Functionality: Using null as an array offset is deprecated, use an empty string instead in <magento_root>/vendor/magento/framework/Component/ComponentRegistrar.php on line 71
```
