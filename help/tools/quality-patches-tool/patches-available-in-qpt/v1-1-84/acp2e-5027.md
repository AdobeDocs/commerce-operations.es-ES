# ACP2E-5027: Los indexadores no terminan cuando el bloqueo de aplicaciones utiliza el proveedor de bloqueo de archivos

El parche ACP2E-5027 corrige el problema en el que los indexadores nunca terminan porque siguen intentando adquirir su propio bloqueo cuando `use_application_lock` está habilitado y el proveedor de bloqueo de archivos está configurado. Esta revisión está disponible cuando está instalado [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84. El ID del parche es ACP2E-5027. Está previsto corregir este problema en Adobe Commerce 2.4.10.

## Productos y versiones afectados

**El parche se ha creado para la versión de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.9

**Compatible con versiones de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.4 - 2.4.9

>[!NOTE]
>
>El parche podría ser aplicable a otras versiones con las nuevas versiones de [!DNL Quality Patches Tool]. Para comprobar si el parche es compatible con su versión de Adobe Commerce, actualice el paquete `magento/quality-patches` a la última versión y compruebe la compatibilidad en la página [[!DNL Quality Patches Tool]: buscar parches &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilice el ID de parche como palabra clave de búsqueda para localizar el parche.

## Problema

Los indizadores nunca terminan porque siguen intentando adquirir su propio bloqueo cuando `use_application_lock` está habilitado y el proveedor de bloqueo de archivos está configurado.

<u>Pasos a seguir</u>:

1. En `app/etc/env.php`, habilite el bloqueo de aplicación para los indizadores y establezca el proveedor de bloqueo en el archivo:

   ```
   'indexer' =>
   array (
     'use_application_lock' => true,
   ),
   'lock' =>
   array (
     'provider' => 'file',
     'config' =>
     array (
       'path' => '<magento_root>/var/lock',
     ),
   )
   ```

1. Ejecute el indizador `catalog_product_category`:

   ```
   bin/magento indexer:reindex catalog_product_category
   ```

<u>Resultados esperados</u>:

El reíndice `catalog_product_category` se completó correctamente.

<u>Resultados reales</u>:

La reindexación nunca se completa.
