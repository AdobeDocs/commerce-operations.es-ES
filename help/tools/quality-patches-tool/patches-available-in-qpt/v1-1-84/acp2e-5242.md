# ACP2E-5242: GraphQL utiliza el ID de la tienda como ID del sitio web durante las solicitudes de complementos al carro de compras

El parche ACP2E-5242 corrige el problema en el que al comprobar la disponibilidad del producto mientras se añaden artículos al carro de compras se muestra un error que indica que no se puede encontrar el sitio web. Esta revisión está disponible cuando está instalado [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84. El ID del parche es ACP2E-5242. Este problema está programado para solucionarse en Adobe Commerce 2.4.10.

## Productos y versiones afectados

**El parche se ha creado para la versión de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.9

**Compatible con versiones de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.9

>[!NOTE]
>
>El parche podría ser aplicable a otras versiones con las nuevas versiones de [!DNL Quality Patches Tool]. Para comprobar si el parche es compatible con su versión de Adobe Commerce, actualice el paquete `magento/quality-patches` a la última versión y compruebe la compatibilidad en la página [[!DNL Quality Patches Tool]: buscar parches &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilice el ID de parche como palabra clave de búsqueda para localizar el parche.

## Problema

La comprobación de la disponibilidad del producto al añadir elementos al carro muestra un error que indica que no se puede encontrar el sitio web.

<u>Pasos a seguir</u>:

1. Inicie sesión en el panel de administración.
1. Vaya a **Administración** > **[!UICONTROL Stores]** > **Configuración** > **[!UICONTROL All Stores]**, haga clic en **[!UICONTROL Create Store View]**.
1. Cree una segunda vista de tienda llamada &quot;store_2&quot;, por ejemplo.
1. Cree un carro de invitados vacío con una solicitud de GraphQL usando el encabezado HTTP &quot;Store: store2&quot;.
1. Registre el ID de carro de compras devuelto.
1. Añada un producto simple al carro de compras con una solicitud GraphQL usando el encabezado HTTP &quot;Store: store2&quot;, el SKU del producto y el ID del carro de compras.

<u>Resultados esperados</u>:

El producto se ha agregado correctamente al carro de compras mediante la petición GraphQL.

<u>Resultados reales</u>:

La solicitud de GraphQL falla y escribe el mensaje &quot;No se encontró el sitio web con el ID ... solicitado. Compruebe el sitio web e inténtelo de nuevo&quot;. a var/log/exception.log.
