# ACP2E-4191: Las solicitudes de API de REST entran en bucle infinito cuando los tipos de EAV y la caché de atributos están desactivados

El parche ACP2E-4191 corrige el problema en el que ciertas solicitudes de API de REST entran en un bucle infinito cuando la caché de tipos y atributos de EAV está deshabilitada. Esta revisión está disponible cuando está instalado [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86. El ID del parche es ACP2E-4191. Tenga en cuenta que este problema se solucionó en Adobe Commerce 2.4.9.

## Productos y versiones afectados

**El parche se ha creado para la versión de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.7-p9, 2.4.8-p2

**Compatible con versiones de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.5 - 2.4.8-p5

>[!NOTE]
>
>El parche podría ser aplicable a otras versiones con las nuevas versiones de [!DNL Quality Patches Tool]. Para comprobar si el parche es compatible con su versión de Adobe Commerce, actualice el paquete `magento/quality-patches` a la última versión y compruebe la compatibilidad en la página [[!DNL Quality Patches Tool]: buscar parches &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=es). Utilice el ID de parche como palabra clave de búsqueda para localizar el parche.

## Problema

Ciertas solicitudes de API de REST entran en un bucle infinito cuando la caché de tipos y atributos de EAV está deshabilitada.

<u>Requisitos previos</u>:

Extensión de Adobe Commerce [!DNL B2B].

<u>Pasos a seguir</u>:

1. Crea una cuenta de cliente e inicia sesión en la Tienda.
1. Añada un producto al carro de compras y abra la página de cierre de compra.
1. En las herramientas para desarrolladores del explorador, abra la pestaña Red e inspeccione las solicitudes REST, como `rest/default/V1/carts/mine/estimate-shipping-methods`.
1. Deshabilite la caché de atributos y tipos de EAV:

   ```
   bin/magento cache:disable eav
   ```

1. Actualice la página de cierre de compra e inspeccione las mismas solicitudes REST.

<u>Resultados esperados</u>:

1. Las solicitudes REST de cierre de compra se completan sin entrar en un bucle infinito.

<u>Resultados reales</u>:

1. Las solicitudes REST fallan con el error HTTP 500 porque el bucle infinito alcanza el tamaño de la pila de llamadas PHP o el límite de memoria.
