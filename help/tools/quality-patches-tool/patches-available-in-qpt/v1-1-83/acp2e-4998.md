# ACP2E-4998: La falta de SKU impide actualizaciones de precios de nivel de volumen para productos válidos

El parche ACP2E-4998 corrige el problema en el que la solicitud de API de REST `POST /V1/products/tier-prices` fallaba por completo cuando no existía un SKU en la carga útil, lo que impedía que se actualizaran los SKU válidos. Esta revisión está disponible cuando está instalado [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83. El ID del parche es ACP2E-4998. Este problema está programado para solucionarse en Adobe Commerce 2.4.10.

## Productos y versiones afectados

**El parche se ha creado para la versión de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.7 - p10

**Compatible con versiones de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) >= 2.4.7 &lt; 2.4.8

>[!NOTE]
>
>El parche podría ser aplicable a otras versiones con las nuevas versiones de [!DNL Quality Patches Tool]. Para comprobar si el parche es compatible con su versión de Adobe Commerce, actualice el paquete `magento/quality-patches` a la última versión y compruebe la compatibilidad en la página [[!DNL Quality Patches Tool]: buscar parches ](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilice el ID de parche como palabra clave de búsqueda para localizar el parche.

## Problema

La solicitud de API de REST `POST /V1/products/tier-prices` falló por completo cuando no existía un SKU en la carga útil, lo que impide que se actualicen los SKU válidos.

<u>Pasos a seguir</u>:

1. Identifique un SKU de producto existente, como `product_dynamic_1`, y un SKU que no exista en el catálogo, como `product_dynamic_001`.
1. Envíe una solicitud de POST a `/rest/V1/products/tier-prices` que contenga ambas SKU en la misma carga:

   ```json
   {
     "prices": [
       {
         "sku": "product_dynamic_1",
         "customer_group": "General",
         "quantity": 5,
         "price": 31.99,
         "price_type": "fixed",
         "website_id": 0
       },
       {
         "sku": "product_dynamic_001",
         "customer_group": "General",
         "quantity": 5,
         "price": 54.49,
         "price_type": "fixed",
         "website_id": 0
       }
     ]
   }
   ```

<u>Resultados esperados</u>:

1. El precio de nivel se guarda para el SKU existente.
1. La respuesta informa del SKU que falta como un error de nivel de elemento.

<u>Resultados reales</u>:

1. La solicitud falla con el error *El producto con SKU &quot;%1&quot; no existe.* para `product_dynamic_001`.
1. No se ha guardado ningún precio de nivel para el SKU existente.
