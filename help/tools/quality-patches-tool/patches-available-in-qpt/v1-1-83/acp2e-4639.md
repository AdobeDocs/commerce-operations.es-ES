# ACP2E-4639: Tipo de elementos de lista de solicitud mal escrito en el esquema GraphQL de Adobe Commerce

El parche ACP2E-4639 corrige el problema en el que el tipo de artículos de la lista de solicitudes está mal escrito en el esquema de GraphQL. El nuevo campo `requisition_list_items` devuelve el tipo `RequisitionListItems` correctamente escrito, mientras que el campo `items` anterior y el tipo `RequistionListItems` permanecen disponibles pero están obsoletos. Esta revisión está disponible cuando está instalado [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83. El ID del parche es ACP2E-4639. Tenga en cuenta que este problema se solucionó en Adobe Commerce B2B 1.5.3.

## Productos y versiones afectados

**El parche se ha creado para la versión de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) B2B 1.5.2 - p1

**Compatible con versiones de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) B2B >= 1.3.4 &lt; 1.5.3

>[!NOTE]
>
>El parche podría ser aplicable a otras versiones con las nuevas versiones de [!DNL Quality Patches Tool]. Para comprobar si el parche es compatible con su versión de Adobe Commerce, actualice el paquete `magento/quality-patches` a la última versión y compruebe la compatibilidad en la página [[!DNL Quality Patches Tool]: buscar parches &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilice el ID de parche como palabra clave de búsqueda para localizar el parche.

## Problema

El tipo de elementos de la lista de solicitudes está mal escrito como `RequistionListItems` en el esquema de GraphQL. El campo `items` anterior y el tipo `RequistionListItems` siguen disponibles, pero están en desuso.

<u>Requisitos previos</u>:

Adobe Commerce con la extensión B2B.

<u>Pasos a seguir</u>:

1. Envíe la siguiente consulta de introspección de GraphQL:

   ```
   {
     __type(name: "RequisitionList") {
       fields(includeDeprecated: true) {
         name
         isDeprecated
         type {
           name
         }
       }
     }
   }
   ```

1. En la respuesta, compruebe el tipo que devuelve el campo `items`.

<u>Resultados esperados</u>:

1. El campo `requisition_list_items` devuelve el tipo `RequisitionListItems` correctamente escrito.
1. El campo `items` y el tipo `RequistionListItems` permanecen disponibles y se marcan como obsoletos.

<u>Resultados reales</u>:

El campo `items` devuelve el tipo `RequistionListItems` mal escrito y ningún campo devuelve el tipo `RequisitionListItems` correctamente escrito.
