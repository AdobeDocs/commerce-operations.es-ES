# ACP2E-3211: Las solicitudes paralelas de complementos al carro de compras crean elementos independientes para el mismo SKU

El parche ACP2E-3211 soluciona el problema de añadir el mismo producto al carro de compras al mismo tiempo en la Tienda crea elementos separados en el carro de compras para el mismo SKU en lugar de combinarlos en un solo elemento. Esta revisión está disponible cuando está instalado [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83. El ID del parche es ACP2E-3211. Tenga en cuenta que este problema se solucionó en Adobe Commerce 2.4.8.

## Productos y versiones afectados

**El parche se ha creado para la versión de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.5-p7

**Compatible con versiones de Adobe Commerce:**

* Adobe Commerce (todos los métodos de implementación) 2.4.5 - 2.4.7-p10

>[!NOTE]
>
>El parche podría ser aplicable a otras versiones con las nuevas versiones de [!DNL Quality Patches Tool]. Para comprobar si el parche es compatible con su versión de Adobe Commerce, actualice el paquete `magento/quality-patches` a la última versión y compruebe la compatibilidad en la página [[!DNL Quality Patches Tool]: buscar parches ](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilice el ID de parche como palabra clave de búsqueda para localizar el parche.

## Problema

Al agregar el mismo producto al carro de compras al mismo tiempo en la Tienda, se crean elementos separados en el carro de compras para la misma SKU en lugar de combinarlos en un solo elemento.

<u>Pasos a seguir</u>:

1. Cree un nuevo producto.
2. Cree una nueva cuenta de cliente e inicie sesión.
3. Vaya a la página del producto, abra **Herramientas de desarrollo** > **Red** y luego agregue el producto al carro de compras.
4. Copie la solicitud de curl (bash) de añadir un producto al carro de compras.
5. Utilice una consulta curl copiada en dos instancias de consola para almacenarla en déclencheur dos veces lo más rápido posible.

<u>Resultados esperados</u>:

- El producto se agrega como un solo elemento de carro, con `qty=2`.

<u>Resultados reales</u>:

- El producto se agrega como dos elementos de carro de compras independientes.
